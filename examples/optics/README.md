# Meniscus optics experiment

An independent Vite + React example using the published `meniscus` package. The image is generated locally as an SVG; no external media is required.

```sh
npm install
npm run dev
```

Change the refractive index, chromatic aberration and light direction. Edit `src/App.jsx` to experiment with the props. The WebGL stage uses frosted glass when WebGL2 is unavailable.

The site's **Edit in StackBlitz** button sends these files to a new browser editor only when clicked. GitHub READMEs support a link to that editor, not an embedded interactive frame.
