## Scope

The meniscus demo site: the landing page (Plates I to IV), the playground (the optical bench) and the docs (the manual). Visitor mode: Persuade on the landing page, Operate in the playground, Read in the docs.

## Audience and job

React developers deciding whether to adopt meniscus. They need to see real refraction in their own browser, understand why it is real, and reach the install line and the API fast.

## Proof

The live effect itself, the ray diagram computed from the library's own displacement profile, and an honest per-browser rendering table. No invented stars, users or benchmarks.

## Constraints

DOM refraction renders in Chromium only. Safari and Firefox visitors see the frosted path and must be told so on the page. WebGL specimens need CORS-safe media. Demo imagery is sourced or authored, labeled, and listed for the user to review.

## Direction contract

THESIS: A live optics plate: glass bends real content, and the ray diagram beside it is computed from the same math. Refuses aurora wallpaper with floating cards.
OWN-WORLD: Two-color textbook print: cool plate stock, blue-black ink, vermilion spot ink for rays and active states, pale cyan only inside glass. Single-weight engraved figures, lettered points, angle arcs; Archivo expanded heads, STIX captions. Dark mode: lantern slide.
STORY: Developers see glass refract live content, drag it, learn why it bends, copy the install line, then open the playground or the manual.
FIRST VIEWPORT: Plate I fills the screen: a specimen field (headline, paragraph, photo) under a draggable glass capsule; section inset A–A at right draws live rays and θ readouts; Fig. 1 caption with live numbers; install line and two actions bottom-left.
FORM: Ray Plate, #1 of 7, seed 69628466.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
